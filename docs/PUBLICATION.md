# APEX 1.0 公开版本说明

版本为 dsh-apex 1.0.0，预设 apex-v1，固定 Harness 基线为 v0.1.6-alpha.1。入口、安装器与运行模块来自已开发的 APEX 1.0；此次公开整理没有修改其运行代码。

## 发布内容

- APEX 1.0 安装入口、Cordis bundle、16 个预设文件、使用与迁移说明。
- 现有 APEX 1.0 回归用例和依赖锁文件。
- [四冲程柴油机对照论文](../papers/diesel-engine-2026-09-16/README.md)、脱敏数据、图表与离线重建脚本。
- 公开目录文件白名单与 SHA-256 校验，以及阻止常见私人路径、凭据格式和原始日志进入发布的检查。

历史已公开版本保留在仓库，安装包只分发 1.0 当前文件。本地研究驱动、完整运行日志、私人配置与开发讨论未纳入本次提交。

## 本次验证

| 检查 | 结果与边界 |
| --- | --- |
| macOS / Node 24 / 匹配 Harness 的原生组件回归 | 162 通过，0 失败，0 跳过；脚本化模型，无付费 API |
| 缺少 Harness checkout 的基础测试入口 | 55 通过，82 明确跳过，0 失败；不计为原生集成通过 |
| 安装器 | 实际创建和挂载、幂等、差异拒绝及错误路径纳入原生回归 |
| 官方构建身份 | official profile、0.1.6-alpha.1、固定提交与 240 项客户端产物摘要匹配 |
| 论文 | 4 页正文、5 页补充材料；41 段正文与 409 个表格单元格完整 |
| 数据与图表 | 与本地论文相比，图表源数据逐字节一致，3 张 PNG 像素一致；评分、用量与耗时未变 |
| PDF 脱敏 | 从公开文本重建；提取文本和元数据无已检查的私人标识，无嵌入附件；修改页已渲染检查 |

原生检查使用隔离的组件夹具和依赖解析目录；依赖只读链接到匹配的已构建 Harness，dsh-apex 解析到本次发布目录，没有复制真实凭据或启动第二个 Web 服务。初次夹具配置遗漏官方模块解析链接而失败；补齐解析链接后完整回归通过，未改变插件实现或放宽断言。

两个 macOS 集成测试补齐了与其他测试一致的 Harness 缺失跳过条件，避免没有宿主构建的公共 CI 报成运行时故障。匹配宿主的完整回归没有跳过这些用例。CI 明确定位为基础与打包检查，不证明 Linux/Windows 的真实宿主能力。

## 复核与维护

在源码目录运行 npm test、npm run check:public 和 npm pack --dry-run --json。原生测试另需匹配且已构建的 Harness，以及可解析相关依赖的测试 profile；DSH_CHECKOUT 与 DSH_HOME 分别指向这些测试资源。勿将缺少宿主而跳过的用例计为通过。

论文公开目录的删减范围与独立复核限制见 [脱敏说明](../papers/diesel-engine-2026-09-16/SANITIZATION.md)。本例每组仅一次生成，不能把工程测试通过或一个成品得分差异解释为普遍能力提升。
