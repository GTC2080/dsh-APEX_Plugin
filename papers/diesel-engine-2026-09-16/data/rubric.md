# 四冲程柴油机 Benchmark 评分量表

总分 100；先逐项计算，再应用最低硬上限。以冻结成品、实际交互、几何与运动数据为依据，不给模型自述或静态标签功能分。固定步骤和假设见 [`protocol.md`](./protocol.md)。

## 计分方式

每项分别记录 `points`、`status`、`evidence`。满分要求该行行为全部有证据；部分实现可按满足的列举要求比例给分，保留一位小数，不重复累计同一行为。缺失记 0；未测量记 `not-verified`，计算已验证得分时不计分，并另列该项可用的剩余分值。不得将未验证项自动当作已确认失败。

结构 S1–S8 按该行列出的适用部件/子部件等权分配，每个部件检查存在性、可辨认形状、装配/连接位置三方面：三者成立为完整，只有静态标签为 0。部件不必使用唯一网格或独立文件，但必须能区分和观察。原文仅涡轮增压器为条件项；确认不适用后，S7 的 2 分在其余必需部件间分配。其他项目不跨组重分配分值。

## K：四冲程运动（24 分，T3、T4）

| ID | 满分 | 验收要求 |
| --- | ---: | --- |
| K1 | 6 | 每缸完整循环为 720°；吸气、压缩、做功、排气顺序正确，活塞方向、曲轴角和阶段标签相互一致，跨周期连续。 |
| K2 | 6 | 曲轴绕主轴旋转，偏心销带动连杆；连杆两端始终对应销中心且中心距不变，活塞沿缸轴运动、行程为 2r；实际几何与声明的机构关系一致。 |
| K3 | 3 | 凸轮轴与曲轴的绝对转速比为 1:2，旋向与传动、相位偏置一致；两个周期无漂移。 |
| K4 | 5 | 凸轮、挺柱、推杆、摇臂、气门升程及弹簧形变同步，气门开闭符合声明正时；关闭时回座，压缩/做功密封阶段无错误持续开启。 |
| K5 | 2 | 柴油机吸入空气、压缩末期喷油压燃的关系正确；喷油状态与选定气缸相位同步，没有用火花塞点火冒充压燃。 |
| K6 | 2 | 速度控制实际改变运动速度；推进依赖时间，调速与不同采样频率下的同相位构型一致，物理转速和播放倍率区分清楚。 |

仅用正弦使活塞上下移动，若导致连杆长度变化或断开，K2 不通过。使用等价数值约束求解同样可通过，不强制采用某段参考代码。理想正时允许平滑启闭；声明的真实气门重叠按其相位核对，不要求所有边界瞬间都严格两阀关闭。

## P：性能与交互稳定性（6 分，T1、T7）

| ID | 满分 | 验收要求 |
| --- | ---: | --- |
| P1 | 3 | 三种固定状态的 30 秒平均有效帧率均 ≥60 fps；每个达标状态 1 分，不能以 rAF/页面自报值代替有效呈现测量。 |
| P2 | 1 | 三种状态逐秒有效帧率均 ≥60，且没有超过 33.33 ms 的长帧；保留 p95/p99 和原始摘要。只平均达标仍不满足此项稳定性要求。 |
| P3 | 1 | 测量环境、实际分辨率、质量档位、采样方法、原始数据和局限可复核，没有隐藏降质、删部件或伪造测量。 |
| P4 | 1 | 旋转/缩放/拾取响应稳定，窗口缩放后显示正常，失焦恢复不发生相位失步或控制卡死。 |

P2 的逐秒与长帧阈值是本 benchmark 对流畅性的操作定义，不是发动机物理定律。帧率样本只代表记录的硬件、画质和测量条件；没有实测则对应项未验证。

## 硬上限

仅在失败得到确认时应用上限；环境不支持或数据缺失标记未验证，不能直接套用失败上限。

| ID | 已确认失败 | 总分上限 |
| --- | --- | ---: |
| C1 | 无可用实时 3D，或主要内容由视频、静态图、2D 动画冒充 | 20 |
| C2 | 成品自身持续致命错误，无法完成核心运行/交互路径 | 40 |
| C3 | 实际循环顺序/周期错误，或曲轴、连杆、活塞缺少可工作的机械联动 | 55 |
| C4 | 没有实际运动的配气机构，或凸轮/曲轴为错误的转速比 | 65 |
| C5 | 没有可用内部观察模式，核心内部件始终不可见 | 75 |
| C6 | 没有任何零件表面悬浮拾取，仅文字列表或静态卡片 | 80 |

最终分数 = `min(原始分, 全部适用上限)`。量表不足以单独证明原题完整完成；必须同时披露缺项、未验证项、精度依据、性能范围和运行状态。视觉评分先看匿名成品证据，再揭示预设与工具轨迹。
